# 文章档位判断（手机版 PWA）

从 PubMed 抽取近期论文，隐去刊名与作者，练习判断发表档位；作答记录与AI评价只保存在你自己的浏览器里。

纯静态页面，无后端、无构建步骤、无第三方依赖。同一份代码可以本地打开，也可以托管在任意静态站点。

## 使用

### 手机安装（Android Chrome）

1. 用 Chrome 打开站点地址
2. 菜单 → 「安装应用」或「添加到主屏幕」
3. 打开后先在「设置」里填写 AI 密钥（可选，不填则只做档位练习，不显示AI盲判与评价）

### 首次使用建议

- 若之前在 Mac 上用过 Python 版本，可在「设置 → 导入JSON」中导入导出的历史文件，历史与去重会接上
- 生成题目需要联网；PubMed 无 key 时限速 3 次/秒，程序已内置间隔

## AI 配置

默认后端 `https://api.deepseek.com/v1`，模型 `deepseek-chat`，兼容任意 OpenAI 格式端点（如本地 Ollama）。

密钥保存在本机浏览器的 localStorage。任何能解锁这台设备的人、或装有读取权限的浏览器扩展都能读取。**建议单独申请一个限额 key，不要使用主账号的 key。**

## 数据与隐私

- 所有记录存在浏览器本地（localStorage），不上传、不同步
- 站点文件本身是公开的，但公开的只有代码与期刊表，不含任何作答记录
- 换浏览器、清站点数据、无痕模式都会丢失记录 → 定期「设置 → 导出JSON」
- 多设备之间不会自动同步；用导出/导入搬运

## 功能

| 页面 | 内容 |
|---|---|
| 练习 | 生成批次、作答（档位必填；主张句、主张类型、三轴、一句依据可选）、揭晓答案、AI盲判、评价与建议 |
| 历史 | 全部作答记录，点开看题目摘要、当时的主张与AI评价；可对缺评价的条目补生成 |
| 分析 | 混淆矩阵、最常见误判、三轴偏移（你 − AI）、每10篇命中率趋势 |
| 设置 | AI密钥与端点、导出/导入JSON |

## 档位口径

| 档位 | 定义 |
|---|---|
| 1 | CNS（Nature/Science/Cell） |
| 2 | IF>20 |
| 3 | IF10–20 |
| 4 | IF5–10 |

三轴：创新性＝与领域默认答案的距离；重要性＝受众面；证据强度＝因果链闭合度。按最弱项定档。

主张类型：描述 / 关联 / 因果 / 机制 / 规则·原则 / 资源·方法。类型决定上限，证据决定是否成立。

## 已知限制

- 不能离线生成题目（依赖 PubMed 与 AI 接口）
- 单批次上限 30 篇；同一期刊每批最多 2 篇
- 历史记录受浏览器 localStorage 容量限制（约 5MB，够上千条）
- 与 Mac 上的 Python 版本不共享数据
